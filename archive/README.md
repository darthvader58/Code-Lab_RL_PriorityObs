# Archived material

The archive is separate from the active trackwise pipeline:

- `legacy_clustered_rl/legacy_notebooks.zip` contains the historical RL
  notebooks that use the older four-month clustered GeoJSON workflow.
- `datasets/` contains the corresponding historical input archives.
- `clustering_notebooks/` contains the threshold-and-cluster dataset notebooks that the track-wise
  pipeline replaced (see `docs/clustering_method.md`): `geos5data_0.5deg.ipynb` (0.5°),
  `geos5data_0.5deg_2yr.ipynb` (0.5°, two-year run), and `geos5data_0.0625deg.ipynb` (0.0625°).

The archived notebooks are retained for reference and are not part of the
active analysis workflow.
